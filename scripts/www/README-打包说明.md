# 「平静的多巴胺阶段」打包说明

一个纯本地、离线可用的块式工作 + 刺激管理工具。数据只存本机（浏览器 / WebView 的 localStorage），无账号、无云同步、不上传。

---

## 文件清单

| 文件 | 作用 |
|---|---|
| `index.html` | 应用入口 |
| `app.css` | 全部样式 |
| `app.js` | 全部逻辑 |
| `data.js` | 静态数据与文案 |
| `icon.svg` | 应用图标 |

---

## 打包目标

用你电脑上的 **PakePlus**（`G:\baozhuang\PakePlus.exe`）把本目录打包成：

- Windows：`平静的多巴胺阶段.exe`（< 5MB）
- Android：`平静的多巴胺阶段.apk`（< 5MB）

> 注意：PakePlus 是图形界面工具，下面按官方流程给步骤；不同版本的按钮名可能略有差异，以你界面上为准。

---

## 一、桌面端（Windows，本地模式，免 Token）

1. 双击打开 `PakePlus.exe`。
2. 新建项目，项目类型选 **静态文件 / 本地网页**（Static / Local HTML）。
3. 把本 `FocusBlocks` 目录整体拖进去，或指向其中的 `index.html`。
4. 应用名填：**平静的多巴胺阶段**（支持中文名）。
5. 目标平台选 **Windows（x64）**。
6. 图标：选 `icon.svg`；若界面只接受 `.png` / `.ico`，先用任意「SVG 转 PNG」在线工具把 `icon.svg` 转成 512×512 的 png 再选。
7. 打包方式选 **本地打包 / Local**（无需 Token，约 30 秒）。
8. 点「打包 / 发布」，完成后下载 `.exe`，双击即可运行。

---

## 二、手机端（Android apk）

### 方式 A：本地模式（优先尝试）

1. 同桌面端步骤，目标平台改选 **Android**。
2. 打包方式选 **本地打包 / Local**，若能直接出 `.apk` 即可。
3. 把 `.apk` 传到手机，安装（首次需允许「未知来源」）。

### 方式 B：云端模式（本地不支持 Android 时，需一个免费 GitHub Token）

1. 去 GitHub 建 Token：
   - 打开 `github.com` → 右上角头像 → **Settings** → **Developer settings** → **Personal access tokens** → **Tokens (classic)** → **Generate new token (classic)**。
   - 勾选 **repo**（全选）和 **workflow**。
   - 点生成，复制 Token（**只显示一次，务必先复制保存**）。
2. 回到 PakePlus，填入该 Token，打包方式选 **云端打包 / GitHub Actions**。
3. 目标平台选 **Android**，发布后等待 GitHub Actions 自动编译，完成后下载 `.apk`。

---

## 三、注意事项

1. **未签名**：PakePlus 不支持签名，产物仅自用。Windows 首次运行可能弹 SmartScreen（点「仍要运行」）；Android 安装需允许「未知来源」，属正常。
2. **数据**：全部在本机，卸载即清空。可在应用内「更多 → 数据 → 导出备份」存一份 json，换设备后用「导入备份」恢复。
3. **通知**：打包成 App 后，系统通知 / 声音 / 震动依赖 WebView 支持程度，个别机型可能不弹通知；应用内仍有到点提示音 + 顶部实时时间。桌面浏览器（Chrome / Edge）里体验最完整。
4. **备用入口**：无需打包时，手机 / 电脑浏览器直接打开 `index.html` 即可用全部功能；浏览器里可「添加到主屏幕」当 App 用。

## 四、应用内功能速览

- **计时**：工作 ↔ 奖励自动循环，一键开始；完成块自动计数。
- **计划**：选第 1~4 周自动套用单块时长与每日目标；内置作息模板 + 音频阶梯。
- **应急**：冷却窗口、射精后低谷、幻想打断、晨间防破戒、物理隔离清单。
- **统计**：今日/近 7 天块数与时长、连续达标、打卡、恢复阶段提示。
- **更多**：奖励白名单、空档决策器、求知任务库、方案模板（普通/ADHD/双相）、深色主题、导出备份、内容屏蔽联动指引。
